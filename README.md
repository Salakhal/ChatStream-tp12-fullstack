## 📖 À propos

**ChatStream** est une application de chat en temps réel complète développée avec **Node.js**, **Express** et **Socket.IO**. Elle permet aux utilisateurs de communiquer instantanément dans différents salons de discussion, d'envoyer des messages privés et de voir en temps réel les utilisateurs connectés.

### ✨ Fonctionnalités

- 🔐 **Authentification simple** - Choix du pseudo et du salon
- 💬 **Messages publics** - Communication en direct dans les salons
- 🔒 **Messages privés** - Commandes `@utilisateur` pour parler en privé
- 👥 **Utilisateurs en ligne** - Liste dynamique des participants
- 📢 **Notifications** - Connexion/déconnexion des utilisateurs
- 🎨 **Interface moderne** - Design élégant et responsive
- 📱 **Responsive** - Compatible mobile, tablette et desktop
- ⚡ **Temps réel** - Communication instantanée sans rafraîchissement

## 🚀 Démarrage rapide

### Prérequis

- Node.js (version 14 ou supérieure)
- npm (inclus avec Node.js)

### Installation

1. **Cloner le projet**
```bash
git clone https://github.com/Salakhal/ChatStream-tp12-fullstack
cd chatstream
```
2. **Installer les dépendances**
```
npm install
```
3. **Démarrer l'application**
```
# Mode développement (avec auto-reload)
npm run dev

# Mode production
npm start
```
4. **Ouvrir l'application**
```
http://localhost:3000
```
